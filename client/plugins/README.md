# Bundled plugins for the deploy tool

Prebuilt binaries shipped with `deploy_plugin.py` / `lockall-deploy.exe`:

| File | Console |
|------|---------|
| `lockall.prx` | PS4 / GoldHEN |
| `lockall_ps5.plugin` | PS5 / etaHEN |

Refresh these from the real build dirs after you rebuild:

```bash
cp ../lockall_plugin/build/lockall.prx .
cp ../ps5_lockall_plugin/build/lockall_ps5.plugin .
```
